# Magnific Icons

Download the selected Magnific/Freepik icons into this folder using these filenames:

- `car.svg`
- `check.svg`
- `clock.svg`
- `mail.svg`
- `location.svg`
- `phone.svg`
- `save.svg`
- `search.svg`
- `shield.svg`
- `trash.svg`
- `user.svg`
- `users.svg`
- `x.svg`

Free Magnific PNG assets require attribution. Premium SVG assets can be used without attribution according to Magnific's icon page.
